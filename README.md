A program that writes a 30-day, $100-start money plan for an AI agent: the Shopify dead-page rescue service. The agent finds small Shopify stores with thin product copy, rewrites each store's weakest page for free, emails the owner the before/after with a $49 Stripe link to put it live, then upsells catalogue-wide fixes and a monthly rewrite watch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` (the plan) into the output directory.
